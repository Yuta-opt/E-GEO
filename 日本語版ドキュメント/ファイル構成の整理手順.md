# 日本語TOEIC研究ファイルの整理手順

## 目的

現在のフォルダには、現役コード・旧方式のコード・途中生成物・最終成果物が同じ階層に混在しています。

次の整理スクリプトを1回実行すると、コードを実行順に並べ、データを工程別フォルダへ移動します。

```text
tools/整理_日本語TOEIC研究ファイル.ps1
```

## 整理後のコード

```text
日本語版コード/
├─ 01_楽天TOEIC商品データをクレンジング.py
├─ 02_実験用TOEIC商品プールを作成.py
├─ 03_TOEIC購入意図テンプレートを作成.py
├─ README.md
└─ 99_旧版/
   ├─ 旧_商品プール200件を作成.py
   └─ 旧_商品プールを最終化.py
```

## 整理後のデータ

```text
日本語版データ/TOEIC/
├─ 00_元データ/
├─ 01_クレンジング済み/
├─ 02_商品プール/
├─ 03_購入意図/
├─ 04_API実験/
├─ 05_分析結果/
├─ 99_旧版/
└─ README.md
```

## 実行手順

VS CodeでE-GEOフォルダを開き、PowerShellターミナルで実行します。

### 1. GitHubの最新状態を取得

```powershell
cd .\E-GEO
git switch ja-toeic-prototype
git pull origin ja-toeic-prototype
```

既にターミナルの現在地が `...\egeo-research\E-GEO` の場合、`cd .\E-GEO` は不要です。

### 2. 変更予定だけ確認

```powershell
powershell -ExecutionPolicy Bypass -File ".\tools\整理_日本語TOEIC研究ファイル.ps1" -Preview
```

`-Preview`では実際のファイル移動は行いません。

### 3. 実際に整理

```powershell
powershell -ExecutionPolicy Bypass -File ".\tools\整理_日本語TOEIC研究ファイル.ps1"
```

### 4. 変更確認

```powershell
git status
git diff --stat
```

CSV・Excelなどの研究データはGitHubへ追加しない設定なので、主にPythonファイルの名前変更、README、`.gitignore`などが表示されます。

### 5. Pythonコードの構文確認

```powershell
uv run python -m py_compile `
  ".\日本語版コード\01_楽天TOEIC商品データをクレンジング.py" `
  ".\日本語版コード\02_実験用TOEIC商品プールを作成.py" `
  ".\日本語版コード\03_TOEIC購入意図テンプレートを作成.py"
```

### 6. GitHubへpush

```powershell
git add -A
git commit -m "Organize Japanese TOEIC research files"
git push origin ja-toeic-prototype
```

## 安全対策

- 元データは削除しません。
- 旧方式のコードと出力は削除せず、`99_旧版`へ移動します。
- 移動先に同名ファイルがある場合は上書きしません。
- スクリプトは繰り返し実行しても、既に整理済みのファイルはスキップします。
- CSV・Excel・API結果は引き続きGitHubへpushしません。
