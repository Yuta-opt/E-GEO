# TOEIC購入意図クエリ作成記録

## 1. 目的

本研究では、英語版E-GEOのリライト戦略を日本語のTOEIC教材へ適用し、
商品説明の書き換えによってLLMの推薦順位が改善するかを検証する。

評価用クエリには、短い検索キーワードと、同一の購入意図を表す長文の購入相談を用いる。

---

## 2. 短文クエリの収集

### 収集日

2026年8月2日

### 収集方法

ラッコキーワードを用いて、Googleサジェストを取得した。

使用した元キーワードは次の14種類である。

- TOEIC 参考書
- TOEIC 問題集
- TOEIC 単語帳
- TOEIC 文法
- TOEIC Part5
- TOEIC Part6
- TOEIC Part7
- TOEIC リスニング
- TOEIC 模試
- TOEIC 初心者
- TOEIC 600点
- TOEIC 700点
- TOEIC 800点
- TOEIC 900点

このうち、保存できたGoogleサジェストCSVは13ファイルである。
`TOEIC 問題集`の単独CSVは含まれていないが、他のCSV内に問題集関連の候補が十分に存在したため、
80件の選定には支障がないと判断した。

### 収集件数

- CSV内の総行数：3,919行
- 重複整理後：3,842語
- 採用候補：80件
- 予備候補：795件
- 除外：2,967件

Googleサジェストに表示された語句を利用しているが、
検索量上位80件を意味するものではない。

## 3. 短文クエリの選定

候補の重複整理、カテゴリ分類、一次選定にはAIを使用した。

その後、研究者が採用候補80件を確認し、次の条件を満たすものを採用した。

1. TOEIC教材を探す検索語として成立する
2. 実際の検索窓へ入力される程度の短い表現である
3. 特定の商品名、著者名、出版社名を含まない
4. 複数の商品が候補になり得る
5. 他の採用クエリと実質的に重複しない
6. 実験対象の6カテゴリへ分類できる

短文クエリは、商品プールや個別の商品説明を参照せずに確定した。

## 5. 長文クエリの作成

各短文クエリについて、その検索意図を維持した長文の購入相談を1件作成した。

長文クエリは、実在人物の投稿ではなく、研究用に作成した合成人物シナリオである。

### 設計方針

- 短文と同じ教材カテゴリ・得点帯・目的を維持する
- 商品名、著者名、出版社名を追加しない
- 個別の商品を有利にする条件を後付けしない
- 購入意図を明確にする
- 80件を共通テンプレートへ単純に当てはめない
- 学習者の属性、背景、期限、悩み、学習時間を分散する
- 相談型、体験談型、箇条書き型、期限強調型、カジュアル型などを混在させる

### 長文クエリの概要

- 作成数：80件
- 完全重複：0件
- 最短：87文字
- 平均：約102文字
- 最長：121文字

長文作成にもAIを使用したが、短文との意味対応と文章の自然さは研究者が確認した。

## 7. 候補商品の再割当

クエリ確定後、次のコマンドで候補商品を再割当した。

```powershell
uv run python ".\日本語版コード\04_TOEIC候補商品を割り当て.py" --require-approved --overwrite
```

各購入意図について、商品プール270件から候補商品10件を選び、
その中から対象商品1件を固定した。

短文と長文では、同じ候補商品10件と同じ対象商品を使用する。

## 8. 再現性に関する注意

- Googleサジェストの取得結果は、取得日や検索サービスの状態によって変わる可能性がある
- 元CSVと途中ExcelはローカルおよびGoogle Driveで保存する
- データ本体、API結果、環境変数はGitHubへアップロードしない
- GitHubにはコード、設定、README、作成手順の記録のみを保存する
