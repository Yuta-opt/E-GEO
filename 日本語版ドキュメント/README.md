### [`TOEIC実験_実施手順と判断記録.md`](TOEIC実験_実施手順と判断記録.md)

## 更新方針

- 研究設計が変わった場合：`README_日本語.md`を更新
- 実際に作業を行った場合：`TOEIC実験_実施手順と判断記録.md`へ追記
- 先行研究の解釈や本研究との対応が変わった場合：`先行研究/E-GEO論文要約_研究対応.md`を更新
- API実験のモデル・設定・費用が確定した場合：実施記録へ実行日とともに追記
- ポスターで採用した最終条件が決まった場合：両方の文書を更新
