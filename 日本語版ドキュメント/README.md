# 日本語版ドキュメント

## 文書一覧

### [`../README_日本語.md`](../README_日本語.md)

研究目的、実験条件、評価指標、スケジュールなど、研究全体の設計概要です。

### [`TOEIC実験_実施手順と判断記録.md`](TOEIC実験_実施手順と判断記録.md)

ESCI案から楽天ブックスのTOEIC教材へ移行した経緯、Octoparseでの収集、クレンジング、商品プール作成、最終化、ファイル整理、購入意図作成までの詳細な実施手順です。

この文書には、実行コマンド、入力・出力ファイル、実際の件数、採用理由、不採用にした方法、再現手順を継続的に追記します。

## 更新方針

- 研究設計が変わった場合：`README_日本語.md`を更新
- 実際に作業を行った場合：`TOEIC実験_実施手順と判断記録.md`へ追記
- API実験のモデル・設定・費用が確定した場合：実施記録へ実行日とともに追記
- ポスターで採用した最終条件が決まった場合：両方の文書を更新
