# TOEIC研究データ

| フォルダ | 内容 |
|---|---|
| `00_元データ/` | Octoparseで取得した300商品の原本。直接編集しない |
| `01_クレンジング済み/` | 明らかに使えない29件を除外し、表記を整えたデータ |
| `02_商品プール/` | 価格欠損と明確な同一商品だけを除いた全商品プール。現時点270件 |
| `03_購入意図/` | 商品から独立して作った80購入意図と、短文・長文クエリ |
| `04_API実験/` | 候補10件、対象商品、元順位、リライト、再順位、APIログ |
| `05_分析結果/` | 集計、統計検定、グラフ、ポスター用出力 |
| `99_旧版/` | 旧方式の出力や再生成前のバックアップ |

## 03_購入意図の現行ファイル

```text
toeic_query_intents_master.csv
toeic_query_intents_review.xlsx
toeic_query_intents_summary.json
```

- `master.csv`：コード処理用
- `review.xlsx`：人間が短文・長文を確認・修正するメインファイル
- `summary.json`：件数、カテゴリ、分割、設計ルールの記録

旧方式の `toeic_purchase_intents_*` は、商品を先に選ぶ設計だったため現在は使用しません。03を実行すると `99_旧版/03_購入意図/`へ退避されます。

CSV・Excel・API結果はGitHubへアップロードしません。
