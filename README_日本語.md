# E-GEO 日本語TOEIC転移実験

英語版E-GEOの実験設計を、日本語のTOEIC教材へ転移して検証する研究です。

## 1. 研究目的

候補商品10件のうち、対象商品1件の商品説明だけを書き換えたとき、LLMによるおすすめ順位がどれだけ変化するかを測ります。

主な研究問いは次の2つです。

1. 英語版E-GEOで得られたリライト戦略は、日本語のTOEIC教材でも有効か。
2. 同じ購入意図でも、短い検索キーワードと長い購入相談でリライト効果は変わるか。

## 2. 現行の実験順序

```text
楽天ブックスの商品300件
        ↓
明らかに使えない29件を除外
        ↓
価格欠損と明確な同一商品を除外
        ↓
商品プール270件
        ↓
商品を見ずに購入意図80件を作成
        ↓
各購入意図に短文・長文クエリを作成
        ↓
各購入意図について商品プールから候補10件を選定
        ↓
候補10件のうち対象商品1件を固定
        ↓
元説明とリライト後の順位を比較
```

最重要ルールは、**商品を先に選んで、その商品に合うクエリを作らないこと**です。購入意図とクエリを先に固定し、その後に270件の商品プールから候補10件を割り当てます。

## 3. 原版E-GEOとの対応

| 項目 | 原版E-GEO | 本研究 |
|---|---|---|
| 言語 | 英語 | 日本語 |
| 商品領域 | 複数カテゴリ | TOEIC教材 |
| クエリ | 長文の購入相談 | 長文＋意味対応する短文 |
| 商品データ | Amazon | 楽天ブックス |
| 候補商品 | 1クエリにつき10件 | 同じ |
| 書き換え対象 | 候補10件中1件 | 同じ |
| Rewriterへの入力 | 商品説明＋汎用指示 | 同じ。評価クエリは原則渡さない |
| Re-rankerへの入力 | クエリ＋候補10件 | 同じ |
| 主指標 | 平均順位改善量 | 同じ |

## 4. データ

### 元データ

2026年7月27日に、楽天ブックスの「TOEIC」検索結果から300商品を取得しました。

主な取得項目：

```text
title_raw
product_url
image_url
isbn_raw
author
publication_info_raw
price_raw
description
```

レビュー数、評価点、売上ランキングなどの人気度情報は使用しません。

### クレンジング

最初の処理では、電子書籍、説明欠損、TOEIC非関連など、明らかに実験へ使えない29件を除外しました。

その後の商品プール作成では、次のルールを採用します。

- 価格情報がない商品を除外する
- ISBN・商品ID・URLが同じ重複を除外する
- 謝恩価格本など、明確に同じ商品だけを統合する
- 商品説明の文字数では除外しない
- 古い教材を除外しない
- 旧版・改訂版・新版は別商品として残す
- 同じ説明文の別商品は削除せず、確認フラグを付ける

現時点の商品プールは270件です。文字数や発売年は除外条件ではなく、後の分析変数として使用します。

## 5. 購入意図とクエリ

購入意図は合計80件です。

| 分割 | 購入意図 | 短文＋長文 |
|---|---:|---:|
| Train | 40 | 80 |
| Validation | 10 | 20 |
| Test | 30 | 60 |
| 合計 | 80 | 160 |

カテゴリ配分：

| カテゴリ | 件数 |
|---|---:|
| 総合対策 | 16 |
| 単語・熟語 | 16 |
| 文法・Part 5/6 | 14 |
| 模試・問題演習 | 14 |
| リスニング | 10 |
| リーディング・Part 7 | 10 |

購入意図作成時には、商品名、商品説明、価格、著者、出版社、URLを参照しません。

### 短文と長文

```text
短文：
TOEIC 730点 総合対策 学習計画を立てやすい

長文：
大学生で、現在は600点前後です。3か月で730点を目指しており、
授業や研究と両立して必要点を取るための教材を探しています。
特に学習計画を立てやすいことを必須条件とし、
スマホや音声で復習できる教材も希望しています。
```

短文は実際の検索語に近い表現、長文は買い物AIへ相談する自然な文章にします。両者は同じ購入意図を表し、商品を有利にする条件を後付けしません。

## 6. 候補商品10件

購入意図とクエリをすべて承認した後、各購入意図に対して270件の商品プールから候補10件を選びます。

候補選定の基本方針：

1. 商品タイトル・説明からクエリとの関連度を計算する
2. 上位候補をLLMで再確認する
3. 比較として不自然な商品を除く
4. 候補10件を固定する
5. 10件の中から対象商品1件を固定する
6. 短文と長文で同じ候補10件・同じ対象商品を使う

購入意図の作成段階では対象商品を決めません。

## 7. 比較条件

| 条件 | 内容 |
|---|---|
| Original | 元の商品説明 |
| EN-Zero | 原版E-GEOの英語プロンプトをそのまま使用 |
| JA-Zero | 英語プロンプトを日本語へ翻訳 |
| JA-Adapted | Train・Validationで日本語向けに調整 |

Testデータは、JA-Adaptedプロンプトの作成・選択に使用しません。

## 8. 評価

主指標：

```text
順位改善量 = 書き換え前の順位 - 書き換え後の順位
```

例：7位から3位になれば `+4` です。

追加指標：

- 平均・中央値
- 上昇、不変、低下の割合
- Top 1、Top 3、Top 5到達率
- 短文と長文の差
- Re-ranker別の差
- リライト条件別の差
- 元説明の文字数との関係
- API費用、トークン数、失敗率

## 9. 現在使うコード

```text
日本語版コード/
├─ 01_楽天TOEIC商品データをクレンジング.py
├─ 02_実験用TOEIC商品プールを作成.py
├─ 03_TOEIC購入意図テンプレートを作成.py
└─ 99_旧版/
```

実行順：

```powershell
uv run python ".\日本語版コード\01_楽天TOEIC商品データをクレンジング.py"
uv run python ".\日本語版コード\02_実験用TOEIC商品プールを作成.py"
uv run python ".\日本語版コード\03_TOEIC購入意図テンプレートを作成.py"
```

03は商品プールを入力に使いません。商品から独立した購入意図を作成し、旧方式の03出力が残っていれば `99_旧版`へ自動退避します。
