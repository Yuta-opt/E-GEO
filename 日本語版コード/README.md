# 日本語版コードの使い方

このフォルダには、日本語TOEIC教材版の実験コードを実行順に置いています。コマンドは、1つ上のリポジトリ直下 `E-GEO/` で実行してください。

## 実行前の準備

Python 3.11以上と `uv` が必要です。初回はリポジトリ直下で、次のコマンドを実行します。

```powershell
uv sync
```

詳しい環境構築方法は、原版の `../README.md` を確認してください。

## 実行順序

### 1. サンプルデータ作成

- ファイル: `01_サンプルデータ作成.py`
- 目的: 架空のTOEIC教材10冊、クエリ3件、書き換え対象商品を作ります。
- 入力: なし
- 出力:
  - `日本語版データ/元データ/toeic_products_sample.csv`
  - `日本語版データ/実験用データ/test_data_ja.json`
  - `日本語版データ/実験用データ/test_selected_products_ja.json`
- API通信: なし

```powershell
uv run python "日本語版コード/01_サンプルデータ作成.py"
```

### 2. データ確認

- ファイル: `02_サンプルデータ確認.py`
- 目的: 2つのJSONで、クエリ、候補商品、書き換え対象が正しく対応しているか確認します。
- 入力: 01番で作成した2つのJSON
- 出力: 画面への確認結果
- API通信: なし

```powershell
uv run python "日本語版コード/02_サンプルデータ確認.py"
```

### 3. 順位付け入力確認

- ファイル: `03_順位付け入力確認.py`
- 目的: 初期順位取得でLLMへ渡すプロンプトを、送信前に確認します。
- 入力: `日本語版データ/実験用データ/test_data_ja.json`
- 出力: `日本語版データ/実験用データ/ranking_prompt_preview.txt`
- API通信: なし

```powershell
uv run python "日本語版コード/03_順位付け入力確認.py"
```

### 4. 初期順位取得

- ファイル: `04_初期順位取得.py`
- 目的: 書き換え前の商品順位をLLMから取得します。
- 入力:
  - `日本語版データ/実験用データ/test_data_ja.json`
  - 利用するサービスに対応したAPIキー
- 出力: `日本語版データ/実験結果/initial_ranking_ja.json`
- API通信: あり
- 課金: 発生する可能性あり

`--execute` を付けなければAPIは呼び出されません。実際の取得では、`--execute` の指定後に確認画面で `y` または `yes` を入力した場合だけ通信します。

OpenRouterを使う場合のコマンド形式:

```powershell
uv run python "日本語版コード/04_初期順位取得.py" --provider openrouter --model "<OpenRouterのモデルID>" --execute
```

このリポジトリ整理時には、04番は構文確認だけを行い、スクリプト自体は実行していません。

### 5. 今後追加する商品説明書き換え

書き換え対象商品の事実を変えずに、商品説明を改善するコードを追加します。原版E-GEOと同様に、書き換え側が検索クエリを直接見ない条件を保ちます。

### 6. 書き換え後順位取得

5番で作成した商品説明を、4番と同じ候補商品・モデル条件で再順位付けします。

### 7. 順位改善の計算

`初期順位 - 書き換え後順位` を計算します。正の値なら順位上昇、0なら変化なし、負の値なら順位低下です。

## 初心者向けの注意点

- 必ず01番から順番に実行してください。
- `日本語版データ/実験用データ/` のJSONを手作業で変更する前に、元ファイルを確認してください。
- 商品やクエリを変更する場合は、まず01番の `products`、`queries`、`selected_indices` を変更します。
- 関数名、変数名、import名、JSONのキー名は変更しないでください。
- `src/` と `data/` は原版E-GEOの領域です。日本語版の実験結果を書き込まないでください。
- APIキーをPythonファイル、README、Git履歴へ書かないでください。
- `.env` の内容を表示・共有・コミットしないでください。
- 04番を実行する前に、プロバイダー、モデル、料金、利用上限を確認してください。

リポジトリ全体の構成と全ファイルの説明は、`../README_日本語.md` を参照してください。
