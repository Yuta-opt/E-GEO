# 日本語版コード

現在使うPythonファイルは、上から順番に実行します。

| 順番 | ファイル | 何をするか | 商品データを使うか | 主な出力先 |
|---:|---|---|---|---|
| 1 | `01_楽天TOEIC商品データをクレンジング.py` | 元Excelを整形し、明らかに使えない商品を除外する | 使う | `01_クレンジング済み/` |
| 2 | `02_実験用TOEIC商品プールを作成.py` | 価格欠損と明確な同一商品だけを除き、全商品プールを作る | 使う | `02_商品プール/` |
| 3 | `03_TOEIC購入意図テンプレートを作成.py` | 商品を見ずに80件の購入意図と短文・長文クエリ案を作る | **使わない** | `03_購入意図/` |

## 重要な設計変更

旧03は、商品を先に80件選び、その商品に合わせてクエリを作る方式でした。この方式では、対象商品が有利になる条件を無意識に入れる可能性があるため廃止しました。

現行03は次の順番です。

```text
購入意図80件を商品から独立して作る
↓
短文・長文クエリを確認・確定する
↓
次工程で270件の商品プールから候補10件を割り当てる
```

## 03の実行

```powershell
uv run python ".\日本語版コード\03_TOEIC購入意図テンプレートを作成.py"
```

旧方式の次のファイルが残っている場合、自動的に `99_旧版/03_購入意図/`へ退避します。

```text
toeic_purchase_intents_template.csv
toeic_purchase_intents_review.xlsx
toeic_purchase_intents_summary.json
```

新しい出力：

```text
toeic_query_intents_master.csv
toeic_query_intents_review.xlsx
toeic_query_intents_summary.json
```

既に新方式の出力があり、再生成する場合：

```powershell
uv run python ".\日本語版コード\03_TOEIC購入意図テンプレートを作成.py" --overwrite
```

`99_旧版/`は以前の条件を再現する保存用コードです。現在の研究では実行しません。
